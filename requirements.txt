                         #   on PyFlink for when a real multi-node deployment earns its cost.
                         #   `brew install apache-flink` has NO `brew services` entry — a
                         #   standalone cluster is not a persistent system service like
                         #   Cassandra/Kafka are, so don't depend on it staying up unattended.
